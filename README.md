## Project target
Industry-neutral trading/distribution ERP MVP, with secure multi-tenancy; organization/approval; supplier/customer/item master data; purchasing/dock receiving/valued acceptance; moving-average inventory and GRNI; supplier invoice + AP + payments; sales/fulfillment/customer invoicing/AR; double-entry General Ledger, reconciliation, evidence and UAT.

## Do not overclaim
A completed build is not an accepted feature. A passing unit test is not proof of SQL isolation or accounting correctness. Missing tests are BLOCKED, not PASS. No Product Owner approval signature or production authorization may be generated by the agent.
